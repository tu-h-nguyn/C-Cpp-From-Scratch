## Getting Started

### Prerequisites

Install a C/C++ compiler such as GCC or Clang.

### Compile and Run C

```bash
gcc main.c -o main
./main
```

### Compile and Run C++

```bash
g++ main.cpp -o main
./main
```

Replace `main.c` or `main.cpp` with the corresponding source file.
